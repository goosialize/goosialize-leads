# Support and feedback

Goosialize Leads uses GitHub Issues for reproducible bugs and feature requests.

## Before opening a bug

1. Update to the latest stable release.
2. Review the README and troubleshooting documentation.
3. Search existing issues for the same problem.
4. Remove passwords, API keys, access tokens, personal data, customer data, and private production URLs from anything you post.

## Report a bug

Open the structured bug form:

https://github.com/goosialize/goosialize-leads/issues/new?template=bug_report.yml

Include the plugin version, Grav version, PHP version, Admin2 version when relevant, browser/OS for UI problems, and the smallest reproducible sequence.

## Request a feature

Open the structured feature request form:

https://github.com/goosialize/goosialize-leads/issues/new?template=feature_request.yml

Describe the user problem or use case first, then the desired behavior.

## Security-sensitive reports

Do not publish credentials, exploit details, personal data, or production secrets in a public issue. Use the private contact route on https://goosialize.com for security-sensitive material.
