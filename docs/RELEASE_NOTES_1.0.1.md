# Goosialize Leads 1.0.1 release notes

Goosialize Leads 1.0.1 is a distribution-readiness patch for the first Grav
GPM submission. Runtime behavior and the supported Grav 2.0.12 product scope
remain unchanged from 1.0.0.

## Distribution changes

- Includes the MIT `LICENSE` file in source and the installable package.
- Adds the required Grav blueprint icon and public repository identity fields.
- Declares the MIT license consistently in the blueprint and Composer metadata.
- Uses Grav's repository-compatible changelog heading and date structure.
- Updates repository status text to reflect the published 1.0.0 release.

## Compatibility

- Grav CMS 2.0.12.
- PHP 8.3 with the Intl extension.
- Native Grav Admin2 and API integrations.

The immutable `1.0.0` tag and its published release assets are not modified by
this patch.
