# Goosialize Leads 1.0.2 release notes

Goosialize Leads 1.0.2 is a public metadata and package-documentation
maintenance release for Grav GPM preparation. Product behavior is unchanged
from 1.0.1.

## Maintenance changes

- Adds the public repository homepage, Goosialize Ltd author and verified
  GitHub Issues/source metadata to Composer metadata.
- Includes the canonical public plugin integration contract in the installable
  package and aligns its status with the shipped version 1 capability.
- Updates repository release-status wording and packaged documentation links.

## Compatibility and upgrades

- Grav CMS 2.0.12 and the existing Grav 2 compatibility contract are
  unchanged.
- Native Admin2 and API integration behavior is unchanged.
- The MIT license is unchanged.
- There are no product behavior or storage schema changes.
- No migration is required from 1.0.1.

The immutable `1.0.0` and `1.0.1` tags and their published release assets are
not modified by this release.
