# CSV export

CSV export is an optional native Admin2 action.

## Enablement

```yaml
admin2_csv_export:
  enabled: true
  max_response_bytes: 131072
```

## Permissions

Export requires both:

```text
api.goosialize_leads.read
api.goosialize_leads.export
```

The export action is not available solely because a user can view the Lead
index.

## Output

The native filename is:

```text
goosialize-leads-YYYY-MM-DD-HHmm.csv
```

The timestamp uses the effective Grav/PHP application timezone. The filename
is generated by the server and is independent of the Admin2 View selection or
current client-side page.

The response is bounded by the configured maximum byte count.

## Spreadsheet safety

Values beginning with spreadsheet formula prefixes are escaped before CSV
serialization.

## Record scope

The export uses the same canonical bounded Lead collection used by the
Admin2 Lead index.

Dynamic filename generation does not change the exported columns, bounded
record selection, response-size limit or authorization contract.

Idempotency sidecars and notification state files are not exported as Lead
records.

## Security

CSV output must not expose:

- filesystem paths;
- idempotency secrets;
- notification routing configuration;
- SMTP or provider credentials;
- raw exceptions.
